# 链接的语义

## 核心问题：如何让多个名字指向同一份数据？

## FAT 的目录项

```c
struct fat_dent {
    char     name[11];      // 8+3 文件名
    uint8_t  attr;          // 文件属性
    uint16_t first_cluster; // 起始 cluster ← 文件数据的位置
    uint32_t file_size;     // 文件大小
    // 时间戳等
};
```

**文件名和元数据绑定在一起，没有分离。**

| 问题 | 后果 |
|---|---|
| 元数据重复 | 两个 dent 指向同一数据 → `file_size`, `timestamps` 谁来同步？ |
| 无引用计数 | 删一个 dent → 不知道还有没有别人在用 → 要么泄漏要么 dangling |
| 修改不同步 | 通过 dent A 追加数据，dent B 的 `first_cluster` 还是旧的 |

→ **FAT 不支持硬链接**

## Linux (Unix) 的设计：分离

```c
// inode — 文件的"本体"
struct inode {
    int      links;     // 有多少个名字指向我？
    int      size;
    block_t  blocks[15];
    // ...
};

// dent — 只是一个入口（边）
// using dent = map<string, inode_t>
struct dent {
    char     name[256];
    int      inode_num;
};
```

**关系：多个 dent → 一个 inode → 数据块**

```
硬链接前：
  "a.txt" ──→ inode_42 ──→ [data blocks]

硬链接 (ln a.txt b.txt)：
  "a.txt" ──→ inode_42 ──→ [data blocks]
  "b.txt" ──→ inode_42 ──→          ↑
                              links = 2

删除 "a.txt" (unlink)：
  "b.txt" ──→ inode_42 ──→ [data blocks]
                              links = 1  → 数据还在
                              ↑ links--，不为 0 就不释放
```

### 关键点

- `link("a.txt", "b.txt")`：在 b 的目录里新建一个 dent，`inode_num = a 的 inode_num`，然后 `inode.links++`
- `unlink("a.txt")`：删除 dent，`inode.links--`，仅当 `links == 0` 时才释放 inode 和数据块
- 硬链接不能跨文件系统（inode 编号只在同一个文件系统内有意义）
- 不能链接目录（防止环 → 需要 GC 或限制深度，POSIX 选择禁止）

### 软链接（符号链接）

```bash
ln -s a.txt b.txt  # b.txt → a.txt
```

b.txt 的内容就是 `"a.txt"` 这个路径字符串。访问时内核自动重定向。

- 可以跨文件系统
- 可以链接目录
- 但原文件被删 → dangling symlink
