# C 语言复杂声明与函数指针

> C 的复杂声明本质是“读法”问题：掌握从内向外、先右后左的读法后，一切声明都能拆开。

## 核心方法：右左法则

1. 找到最里面的**标识符**（变量名）；
2. **先向右**看：`[n]` 是数组，`(参数)` 是函数；
3. **再向左**看：`*` 是指针；
4. 遇到 `(` 分组就跳出去，继续“右→左”；
5. 最后是类型说明符。

## 指针与数组：优先级陷阱

```c
int *p[3];    // p 是数组，含 3 个 int*   （[] 优先级高于 *）
int (*p)[3];  // p 是指针，指向含 3 个 int 的数组
```

用右左法则：

- `int *p[3];`：p 先向右看 `[3]` → 数组；再向左看 `*` → 元素是指针 → **指针数组**。
- `int (*p)[3];`：括号让 p 先向左结合 `*` → 指针；再向右看 `[3]` → 指向 int[3] → **数组指针**。

口诀：**`*` 修饰离它最近的“名字”，`[]` 和 `()` 优先级更高**，除非用括号改变结合顺序。

`const` 同理，看它在 `*` 的哪边：

```c
const int *p;   // 指向 const int 的指针：*p 不能改，p 可以改
int *const p;   // 常量指针：p 不能改，*p 可以改
const int *const p; // 两个都不能改
```

## 函数指针

```c
int add(int a, int b) { return a + b; }

int (*fp)(int, int);   // fp 是指向“返回 int、接收两个 int”的函数的指针
fp = add;              // 函数名即地址（&add 也行）
fp(3, 4);              // 调用，等价于 (*fp)(3, 4);
```

注意 `int *fp(int, int);` **不是**函数指针——fp 先结合 `(int, int)`，它是一个返回 `int*` 的**函数**。

### 典型用途

**1. 回调函数**（把行为传给框架）

```c
int cmp(const void *a, const void *b) { return *(int*)a - *(int*)b; }
qsort(arr, n, sizeof(int), cmp);   // qsort 在内部调用你给的 cmp
```

PA2 的 MMIO 就是这种模式：`map_read` 命中设备地址时触发绑定的 `rtc_io_handler` 回调（见 [[ICS-PA2 note]]）。

**2. 函数指针数组**（命令分发 / 状态机）

```c
int (*ops[])(int, int) = {add, sub, mul, div};
ops[opcode](a, b);   // 用下标选函数，比 switch 清爽
```

**3. typedef 简化 + 返回函数指针**

```c
typedef int (*BinOp)(int, int);
BinOp fp = add;                          // 声明一下就简单了

int (*get_op(char c))(int, int);         // 函数：参数 char，返回指向函数的指针
// 读法：get_op 是函数 → 返回指针 → 指向“返回 int、参数 (int,int)”的函数
```

## 经典复杂声明拆解

```c
void (*signal(int sig, void (*handler)(int)))(int);
```

这是 Linux 里 `signal` 的真实声明，一层层剥：

- 最内层 `signal(int sig, void (*handler)(int))`：signal 是**函数**，参数是 `sig` 和一个函数指针 `handler`；
- 外面 `(*...)`：它返回一个**指针**；
- 最右边 `(int)`：这个指针指向“接收 int、返回 void”的函数。

结论：signal 接收信号编号和回调函数，返回旧的处理函数指针。

综合题：

```c
char (*(*x[3])(void))[5];
```

- `x[3]`：x 是含 3 个元素的数组；
- `(*x[3])`：元素是指针；
- `(*x[3])(void)`：指向“无参函数”；
- `(*(*x[3])(void))`：函数返回指针；
- `[5]`：返回的指针指向 `char[5]`。

即：x 是数组，含 3 个函数指针，每个函数返回指向 char[5] 的指针。

## 实用建议

- 别硬写复杂声明，用 typedef 分层拆解（先定义函数指针类型，再组合）；
- 读不懂时用 `cdecl` 工具或网站自动翻译；
- 函数指针本质就是**代码段里的一个地址**，与普通指针没有区别，调用就是跳转到那个地址执行——这正是 [[OS-lecture-06 进程的地址空间|OS 课“给 main 赋值给函数指针”]] 和 [[ICS-PA3 note|PA3 中断回调 simple_trap]] 背后的原理。
