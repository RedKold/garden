## 1. word count

给定一系列英语词语，以空格(词语间可能不止一个空格)或换行分割，输出每个词语以及其出现次数

#### 输入格式：(例)

```
one two  three five
six six two seven eight
ten ten ten ten six one
two   two  five  nine ten
three three seven eight   ten
```

#### 输出格式：
每行由两部分组成，第一部分是单词，第二部分是出现次数，输出顺序先按照出现次数由大到小，次数相同则按照字典序排列。
例：上面的例子的输出
```
ten 6  
two 4  
six 3  
three 3
eight 2
five 2 
one 2  
seven 2
nine 1
```

解法：非常容易的题目，使用C++的话利用stl里面的map就秒了，每输入一个新的单词`s`就将`pair<string int>(s, 1)`存入map，每输入一个已有的单词就通过map::find找到该项的`iterator iter`，并通过`iter->second++`来修改次数。由于map是自动按照key排序的，所以此时已经按照字典序存储完毕了，稍微考虑一下如何优先按照出现次数排序，我的做法是先遍历一遍map，得到出现次数最高是多少(上例中为6)，设为i，然后再进行for循环，外层从i = 6开始遍历，每次循环i--，内层遍历map，遇到和i相等的项就输出即可。

>  repo owner补记：一种stl用得更聪明的做法

>   }

## 3. SafePtr(本题提供了C,C++,Java语言模板，这里以笔者使用的C++为例)

指针可以用于指示一个地址，但是指针本身却没有进行一些诸如越界之类的检查，你现在要实现一个模板类SafePtr，构造一种安全指针，附加以下三种报错形式：
- bad free: 在安全指针所指的空间已经被释放后再次free指向该空间的指针，或者free一个没有指向数组对象首元素的安全指针
- out of bound: 当安全指针所指的位置不在申请的数组范围内时，使用此安全指针(store/load)访问该空间。
- use after free: 在释放某安全指针指向的空间后还使用指向该空间的指针进行访问(store/load/offset)

Tip: 可以使用一些共享数据结构来在指向相同空间的安全指针之间共享对象，本题不检测内存泄漏。

需要实现的方法:
```
SafePtr(size_t size)  

描述：为安全指针申请长度为size的空间，保证size>0
用法示例：SafePtr<int> sp(4);
```
```
SafePtr(const SafePtr &)    

描述：创建并返回一个新的SafePtr，新的安全指针与原指针指向相同的空间
用法示例: auto sp2 = sp;
```
```
SafePtr offset(size_t n)    

描述：返回一个新的SafePtr，新的安全指针指向的位置为原安全指针指向位置偏移n格，n可能为负数
用法示例: 
    auto sp3 = sp2.offset(3);
    auto sp4 = sp3.offset(1); // 实际上已经out of bound，但是未访问不报错
```
```
void store(T e)    

描述：将输入的元素存储到指针当前所指的空间
用法示例: 
    sp3.store(42); // 将42存储到sp3所指的位置，其实是sp所指的位置偏移3格
    sp4.store(0); // 报错：out of bound
```
```
T load()    

描述：返回指针当前指向的元素(T的含义详情看类模板)
用法示例: 
    int a = sp3.load(); // a = 42
    a = sp4.load(); // 报错：out of bound
```
```
void free()    

描述：释放该指针指向的空间
用法示例: 
    sp3.free() // 报错：bad free，因为指向的不是数组第一个元素
    sp.free() // 释放sp指向的空间
    sp2.free() // 报错：bad free
    sp3.free() // 报错：bad free
```

C++模板如下：
```cpp
template <typename T>
class SafePtr{
public:
    SafePtr(size_t size){}

    SafePtr(const SafePtr &){}

    SafePtr offset(size_t n){}

    void store(T e){}

    T load(){}

    void free(){}
}
```

样例如下：
```c++
SafePtr<int> sp(4);
auto sp2 = sp;
auto sp3 = sp.offset(3);
auto sp4 = sp3.offset(1);
sp3.store(42);
sp4.store(0); // throw std::runtime_error("out of bound");
sp3.free(); // throw std::runtime_error("bad free");
assert(sp3.load() == 42);
sp.free(); // 释放sp所指空间
sp2.free(); // throw std::runtime_error("bad free");
sp3.load(); // throw std::runtime_error("use after free");
sp4.free(); // throw std::runtime_error("bad free");
```

笔者的实现如下：
```cpp
template <typename T>
class SafePtr{
public:
    T* array;
    int* length;
    int index;

    SafePtr(size_t size){
        array = new T[size];
        length = new int;
        *length = size;
        index = 0;
    }

    SafePtr(const SafePtr & sp){
        this->array = sp.array;
        this->length = sp.length; // 直接复制指针就行了，指向同一个数字
        this->index = sp.index;
    }

    SafePtr offset(size_t n){
        if(*length == 0){
            throw std::runtime_error("use after free");
        }
        SafePtr<T> sp(0);
        sp.array = this->array;
        sp.length = this->length;
        sp.index = this->index + n;
        return sp;
    }

    void store(T e){
        if(*length == 0){
            throw std::runtime_error("use after free");
        }
        if(index < 0 || index >= *length){
            throw std::runtime_error("out of bound");
        }
        array[index] = e;
    }

    T load(){
        if(*length == 0){
            throw std::runtime_error("use after free");
        }
        if(index < 0 || index >= *length){
            throw std::runtime_error("out of bound");
        }
        return array[index];
    }

    void free(){
        if(*length == 0 || index != 0){
            throw std::runtime_error("bad free");
        }
        *length = 0;
        // repo owner补记：此处可以 delete[] array 减少泄露的内存
    }
}
```
值得注意的是，虽然说不检测内存泄漏，但是如果你没注意处理这个，比如在完成offset时为新创建的sp申请了一定空间，再修改sp.array, sp.length等从而使原来的空间泄露，那么很有可能在最后一个样例喜提MLE一则。

> repo owner补记：使用stl里的智能指针可以写出一个很优雅且没有内存泄漏的实现
>
> ```c++
> template <typename T>
> class SafePtr {
>   shared_ptr<vector<T>> ptr;
>   size_t index = 0;
> 
> public:
>   SafePtr(size_t size): ptr(make_shared<vector<T>>(size)) {}
> 
>   SafePtr(const SafePtr &) = default;
> 
>   SafePtr offset(size_t n) const {
>     SafePtr other(*this);
>     other.index += n;
>     return other;
>   }
> 
>   void store(T e) {
>     if (!ptr || ptr->empty()) {
>       throw runtime_error("use after free");
>     }
>     if(index >= ptr->size()){
>       throw runtime_error("out of bound");
>     }
>     (*ptr)[index] = e;
>   }
> 
>   T load() const {
>     if (!ptr || ptr->empty()) {
>       throw runtime_error("use after free");
>     }
>     if(index >= ptr->size()){
>       throw runtime_error("out of bound");
>     }
>     return (*ptr)[index];
>   }
> 
>   void free() {
>     if (!ptr || ptr->empty() || index != 0) {
>       throw runtime_error("bad free");
>     }
>     ptr->clear();
>     ptr.reset();
>   }
> };
> ```
