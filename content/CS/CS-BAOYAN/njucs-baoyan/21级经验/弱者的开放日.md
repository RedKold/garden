## 夏令营

笔者3-4月主要时间用来找实习，几乎没有准备开放日，而再之前的时间全部用于cs和无畏契约，故复习时间十分紧张，也为开放日过程中的极度焦虑埋下伏笔。得知5.18开始笔试，五一假期爽上分数日后开始着手准备夏令营。

### 笔试

开始准备笔试时，打算先完整复习一遍408，然后在复习一下离散、编译、大数据。软工。这样就比较全面，之后的面试也能用得上。遂开始看王道408操作系统网课。

大约一周后，看完了操作系统。

这时时间已经来到了5.12，我开始急了。这么够吧多的科目，一周才看完一门，这样下去必然大寄特寄，何况每天还要两个半小时来做无畏契约的每日任务，时间更是紧张。于是重新进行规划，呢喃没有单独开计组，我直接选择放掉；计网准备实习的时候看了一点，也选择放掉应用层、传输层、网络层；数据结构之前考CCF-CSP小刷了一点题目，稍微看看即可；这样还有充分的时间复习离散，编译等内容，想想还是很光明的，一周也够了。

然后看了三天计网链路层。

不是，怎么就只有两天了😭？

这时感觉真来不及了，加之前些年据说不会笔试不会刷本校，刷了也可以复活去预推免，决定心态至上。用一天速览了没看科目的期末复习笔记，然后用一天打游戏打了个爽。

来到笔试当天，笔试时间1小时，单选40+多选30共70题，复习最长的操作系统和计网基本没考，数据结构考了一些单选，考了几个背包dp，别的题目就毫无把握了，特别是多选选项繁多同时有大量编译、PL内容。

做完心情是比较忐忑的。一方面，20经验贴中提到往年题会大篇幅复现，因此有些掉以轻心，疏于复习，但今年只复现了一个1分的单选，往年题会大篇幅复现的情况并没有发生。另一方面，多选据说错选少选无分大多数多选我都没有全对把握，而多选占了你妈70分。

笔试结束后因为感觉不一定能入围线下了，在公布结果之前就去写写作业，打打游戏，暂时停滞了开放日的复习。

5.20校庆当天下午公布入营结果，最终有惊无险入营线下。

事实上还是有10-20名的本校学生在这一阶段折戟，因为希望各位后来者还是不能太掉以轻心，能够有一个月左右的提前量，合理规划就能做到比较周密的复习准备了，这对后面面试也有一定好处。


### 机试

5.20校庆当天得知入营线下，觉得既然已经入营，就全力以赴不留遗憾才好，因此狠狠刷了两周机试题目。虽然实际上每天还是要打三个小时游戏。

机试准备上，参考了去年开放日题型，决定把主要精力放在DP上，再稍微准备下图论。理由是去年夏令营重点考察了dp，且都是板子题，而预推免则几乎全是大模拟。你知道的，dp在oiwiki上的板子题，刷过就有，没刷过就寄，至于大模拟，只能祝他好运。于是就照着洛谷题单和oiwiki狠狠刷dp，虽然刷的并不快，但是一天还是可以吃下一个题型的。就这样把板子题基本刷了一遍。

大约5.27左右，dp刷的七七八八了。回顾去年的经验帖子，很多哥们被卡输入导致签到题寄了，于是专门用一天复习了输入和STL。

如果用C++编程，STL的vector,priority_queue,list,map,unordered_map,set,unordered_set容器及其对应操作还是应当熟悉掌握的，也可以顺带复习下诸如这些容器及操作是否线程安全之类的语言相关知识，也是为面试做铺垫。

输入上面，下面模板可以处理不定行数，每一行不定空格的输入，基本能用这个就无敌了

```c++
string line, token;
stringstream ss;
while (getline(cin, line)) {
    ss.clear();
    ss.str(line);
    while (ss >> token) { ... }
}
```
5.31晚，作为考前放松，我打了3局无畏契约的rank，均大比分获胜。

但是上床躺下之后，心态却一点也不放松，可能是准备时间还是太短，也可能是大学前三年太过松弛，在这临门一脚，我失眠了。

在床上我想起四月份我老爹老妈来南京出差，叫我出去住了两晚酒店，当时我刚面完tx的hr面一周，室友和我一起面已经收到offer，而我却迟迟没有消息。这种“有一点希望，但是不多”的情形让我失眠了，直到四点还没入睡，老妈起夜看到我还没睡，就让我吃了片洋硝西泮，服用药物之后我很快睡着了。第二天老妈问我要不要给我留两片以备不时之需，当时我认为我优秀的意志品质可以克服这一症结，就没有要。现在想来我似乎并没有优秀的意志品质😭。

6.1凌晨四点，我仍然没办法入睡，心跳的很快，下床看了会IEM达拉斯的直播，发弹幕和主播弹幕聊了会天，分享了现在很难受的失眠境地，弹幕纷纷安慰我，并劝我别看手机，闭目养神一会也是好的。这种紧张的时刻，陌生人的简单安慰却是各位的有效，我心情稍微平复了一些，继续上床尝试入睡。虽然还是没睡着，但是心跳没有之前那么快了，顺势闭目休息了三个多小时。

6.1早上七点半，已经通宵的我决定起床，此时仍然很紧张，但是事已至此紧张未必是坏事，要是没有分泌的肾上腺素，我恐怕还没开考就得睡着了。喝了三杯500ml罐装咖啡，进入考场了。

三道题目仓库里都有，我不再复述题面。[2024夏令营开放日原题回忆版](https://git.nju.edu.cn/Iroha/njucs-baoyan/-/blob/main/21%E7%BA%A7%E7%BB%8F%E9%AA%8C/2024.6.1%E5%BC%80%E6%94%BE%E6%97%A5%E4%B8%8A%E6%9C%BA%E9%A2%98%E7%9B%AE%E5%9B%9E%E5%BF%86%E7%89%88.md?ref_type=heads)

第一题签到题目，所幸复习了stl，即使缺少睡眠也不影响完成，20分钟AC。

第二题题面略长，样例说明中提到只有一个大样例，三分类问题按正确率给分，正确率低于50%不得分，因为害怕爆0，所以决定断舍离，直接转战图三。事实证明这个决断是绝对正确的，在严重缺乏睡眠的情况下，即使我能想到斜率之类的特征，也很难把边界修好，许多传统高手都是耗费大量时间在t2且最终得分不高导致折戟。

第三题是一个大模拟实现安全指针，本来以为要设计引用计数之类的，结果完全没有，填几个api就好了。题目允许三种语言，虽然笔者常用语言是C++，但是确实没怎么使用过throw，怕忙里出错，选择了C语言实现。呢喃的课程实验虽说大多被诟病是答辩，但是做多了这些实验，这个大模拟还是手拿把掐，可以认为是某种意义的本校保护吧。笔者开了一个巨大数组模拟堆空间，接下来的实现就相对容易了。可能由于过度紧张加上缺乏睡眠，第一遍实现的时候我完全没注意到指针offset可以为负数，即使他专门用括号提醒了。因此第一次提交只有62分，后面还剩半小时的时候注意到了这点，做了一些修改，但是大框架终究是按没有负数实现的，遗漏颇多，而重新写一版感觉来不及了，最终修修补补拿到82分。

最终机试以182分收尾离场，出考场长舒一口气，整个人瘫软地坐在地上，五分钟后才站起身。个人对这个分数已经满意了。在凌晨五六点还没睡着的时候，我已经做好了拿签到题80+骗分30的110分离场的打算。最终在考场上的舍t2做t3的判断帮助我拿到了我能拿到的大部分分数。个人认为大多数踏实准备的同学，即使可能和我一样准备方向出错，也有拿到200分的能力。

本校生而言，机试在整个开放日占决定性作用，据笔者的身边统计学，最终入营结果机试成绩大于等于200的都是学硕，120到200都是专硕，120-则是WL。完成签到题并且选择合适的题目拿到一定的分数就大概率有offer了。而细心一点拿到普通人类上限的200就有学硕了。

机考复习上，不建议大家和21级许多哥们一样过拟合从而all in某个内容，例如笔者及笔者室友考前全在复习dp，结果连dp的毛都没见到。考前针对性的复习dp和图论易考板子，参加一次csp(呢喃会报销)锻炼下大模拟能力感觉就基本够用,剩下的就是考运和临场了😄。
### 面试
时间拉回到5.20公布入营结果，当时我根据20级仓库情报，判断面试也是有一定权重的，因此也做了一定的准备。

已知面试时遇到不会的问题可以直接告诉老师“我不会换一道”，因此比起广度优先复习，拥有一定面试引导技巧的深度优先复习显然更能帮助通过面试。因此我从5.20开始每天花了一个小时左右准备了面试内容，大致有以下几个大板块：

* 英语基础：科目介绍、自我介绍，别的知识点介绍放在了每个科目复习下顺道复习。
* OS：宏观OS设计、线程与进程（进程间切换、通信、调度算法）、互斥与同步（概念、互斥锁和自旋锁）
* 计网：tcp/ip、三次握手四次挥手、http、拥塞控制（计网和OS主要是三四月找实习背的面经，加以一点拓展）
* DS： 排序算法、图的最短路算法、最小生成树算法、红黑树、哈希表（DS我做了重点准备，因为科目介绍中我选择的是DS作为我的最擅长科目，既然准备往这边引导，多做点准备肯定没错）
* C++： 面向对象、STL底层实现与特性，线程是否安全
* 离散： 群的定义、格的定义、贝叶斯定理

一周半的时间里，我把上述内容以及一些会用到的英文词汇准备了一遍。

回到6.1，结束机试之后，稍微了解了一下大家机考得分情况，基本就是传统高手砍下200分，以及大量的100-200，感觉这个分数优营机会不小，之前过于紧张的情绪得以缓解，稍微复习了一下午之前准备的英语词汇，就去打无畏契约了😋，之后一觉睡了12小时，醒来直接去参加面试了。

可能是20级夏令营战况过于惨烈，今年本校应该还是做了一定保护。虽然面试原则上是“双盲”，但本校全安排在6.2下午。

6.2下午，现场进行了抽签分组，每组三位老师，十位同学，排队面试。面试过程一位同学进入密闭房间，其余同学在外等待。每人面试时间10分钟，会有人计时，时间到了回答完最后一个问题就结束。过程中是偷听不到房间内的情况的，但是在前面序号的同学可以把情报带出来供后面同学参考。笔者当时序号是3，1号的哥们带出来的提问有两三个直接原封不动地又问了我，所以这个环节的互帮互助还是很有价值的。

面试过程中，老师A先让我用英文介绍自己最擅长的科目，因为战术储备有这一环，遂大喜，圣经吟诵。我的英文回答是回答DS是最擅长的科目，其中有一句“program = data structrue + algorithm”，老师A就顺着问了我理解的算法和数据结构课程的区别与联系，之后还问了我在实际项目中使用了什么数据结构与算法。这两个问题一出，我信心大增，因为本来就打算把老师的提问往这个方向引导。在最后使用的数据结构与算法中我提到了在开发的游戏中使用了图的最短路算法。

老师B也接着我的话，连续追问了几个图的最短路算法、复杂度、优化，这些都正中我的下怀，于是面试进程愉快的过半了。老师B的最后一个问题是我编程过程中在编译时刻、运行时刻分别遇到过哪些bug，所幸这个问题1号同学也被问道，于是我在开始面试前5分钟稍微做了点准备，自我感觉也回答的不错。

老师C顺着我一开始说的游戏开发问了一个偏智力题的问题，说我的游戏人物有一个摄像机获取信息，但显然是不够的，问几个摄像机获取信息才是全面的，这个问题我有点发懵，随便答了答地球要三颗卫星通信，所以按同样的分布放置三个摄像机即可，感觉回答牛唇不对马嘴🤣。之后问了我二部图和判断二部图的算法，我现场想起来了，但计时人员说时间到了，老师C就最后换了个思政问题，遂放我出来了。

因为面试流程基本被我预想的战术给cover到了，所以面试出来后还是很开心的，给后面同学提供情报后就去和朋友唱K了，结束了整个开放日。

事后，从结果来看，这次夏令营面试的影响微乎其微，无论是面试顺利过关，还是备受折磨，让老师连换四五个问题，都没有很大地影响最终结果。基本学硕、专硕、WL的发放严格按照机试成绩发放，传言有导师直言，所有本校面试者分数都几乎一致，虽然无从考证，但个人感受也是如此。但去年面试成绩还是有一定程度影响的，无法确保明年的情况，因此还是做足准备比较好。不过反过来说，即使面试感觉很糟糕，机试拿到了相对可以接受的成绩，应该也还是有不错的结果的。
## 最后的最后

6.12上午，最后一节编译原理课上，我和邻座的好哥们相继收到了邮件，都获得了专硕优营资格。对于许多高手来说，通过开放日可能如饮水一样轻松，但对于笔者这样的弱者而言则完全是另外一番光景。
经历三月份每天猛背八股猛刷算法，最终折戟hr面，从而自暴自弃，放弃找实习转而投入准备开放日。我对不确定的未来，以及这段看得到希望却只能得到绝望的当下十分焦虑不安。幸在呢喃最终还是在这个时间节点给了我一个确实的去处，让我得以平复烦躁的心。
截止笔者完成这篇流水账，21级夏令营结果还没有完成统计，但就个人身边统计学，21级夏令营比起惨淡的20级夏令营结果应该还是好上不少，在没有重大失误的情况下，多数人还是获得优营。所以即使是和笔者一样，各方面平庸的弱者，只要合理准备，还是能有所收获的。
