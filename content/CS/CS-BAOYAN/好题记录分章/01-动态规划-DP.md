# 动态规划（DP）

> [!summary] 类型总结
> 动态规划的核心是：把原问题拆成有依赖的子问题，用数组/哈希记录子问题答案，避免重复计算。写题时先回答四个问题：**状态怎么定义？转移方程是什么？边界是什么？遍历顺序是什么？**
>
> - **完全背包**（货币系统 P5020）：多面值能否凑出金额，按金额从小到大做 `f[j] |= f[j-a[i]]`，能由更小面值凑出的金额直接删除。
> - **记忆化搜索 → 递推**（188 买卖股票 IV）：`dfs(i, j, hold)` 直观翻译成 `dp` 数组，注意"交易次数只在买入/卖出时减一"，不要重复计数。
> - **排序 + DP + 二分**（2054）：先按结束时间排序，二分找"不重叠的前一个事件"，配合前缀最大值取最优。
> - **状态压缩 DP**（1411 涂色、P4310 绝世好题）：把多维状态压成整数 key 记忆化；P4310 按二进制位维护最长子序列，把 O(n²) 降到 O(n·log V)。
> - **LCS 衍生**（712）：删除最少 = 保留最大公共子序列，转化为"最大和公共子序列"后拿总和去减。
> - **树上 DP**（3562 占位）：状态挂在树节点上，自底向上合并子节点答案。

感觉还是挺有趣的. 洛谷这道题其实是这道题的强化


这里最重要一个 **insight** 就是： 你有一个货币系统，面值用数组给出 `int a[]`
怎么证明可以去掉其中的某些金额，从而化简呢？


- **首先**，可以粗略想一下：我们应该尽可能和第一个货币系统 $(n,a)$ 保持一致。勿增实体。我们猜测 $B=(m,b)$ 是 $A=(n,a)$ 货币系统的一个子集，即 $B\subset A$ 或者 $B=A$ 
- 引理 1：即 $B\subset A$ 或者 $B=A$ 
	- 证明：
		- **反证法**。如果 $x \in B,x\not\in A$ （这里指的是数组中的元素），则一定有 $A$ 中的某些元素 $a_{1},a_{2},\dots ,a_{i}$ 可以组成 $x$（因为 $A$ 和 $B$ 货币系统等价的假设 ）
		- 则这些元素，$B$ 一定都可以表示（同样是货币系统等价的假设）
		- 则去掉 $x$，$B$ 能表示的货币一定仍然和 $A$ 等价，去掉 $x$ 将使得 $B$ 元素更少，故原来的 $B$ 不是最优的，矛盾。
- 引理 2：最优的 $B$ 中的元素不可以互相表示。
	- **显然**，可以用其他元素表示的元素必然可以去掉而不影响张成的**货币集合**
- **最终解**：
	- 既然 $B$ 是 $A$ 的一个子集，且 $B$ 中的元素不可以互相表示，那么我们只需要删除 $A$ 中的可以互相表示的元素，剩下的元素个数就是我们要的结果了。
	- **互相表示**：
		- **可以看做一个完全背包问题**
		- 金额 $j$ 能被表示记录为 $f[j]$，则 $f[j]=true,\text{if } f[j-a[i]],\exists i$ 
		- 真正更新的时候，我们可以从小到大遍历金额。（因为大金额能被小金额组成，这需要一个排序），然后每轮更新，更新金额 $f[j]$ 能否被表示的信息。
		- 记得对 $ans$ 做更新。

#### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
#define MAX_A 105
#define MAX_AI 25005
int solve(int n, int a[]);
int main()
{
	int T;
	scanf("%d", &T);
	for(int i=0;i<T;i++){
		int n=0;
		scanf("%d", &n);
		int a[MAX_A];
		memset(a,0,sizeof(a));
		for(int j=1;j<=n;j++){
			scanf("%d", &a[j]);
		}

		int ans=solve(n,a);
		printf("%d\n",ans);
	}
}

int solve(int n, int a[])
{
	int f[MAX_AI];
	memset(f,0,sizeof(f));

	// not set, f[0] could be 1
	f[0]=1;
	// sort the a, from low to high. because one can only be composited by smaller ones
	sort(a+1, a+n+1);
	
	int ans=n; // we found the one who can be compose by lower ones, and delete it;	
	for(int i=1; i<=n; i++){
		if(f[a[i]])	{
			ans--;
			// already know, jump
			continue;
		}
		// update the f[a[i]],
		// f[a[i]] could be composed by smaller coins + a[i]coin, itdepends on f[j-a[i]];
		for(int j=a[i]; j<= a[n]; j++){
			// if f[j]==0, but some f[j-a[i]] could be composed, then it can be composed
			// OR is needed, for if f[j]=1, we don't want to change that;
			f[j]=f[j] || f[j-a[i]];
		}
	}
	return ans;
}
```

### [188. Best Time to Buy and Sell Stock IV](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iv/)
#### 思路

#### Code

**如果用记忆化搜索**：

这里要注意边界情况：
- 如果 `j<0`，即不合法的购买，我们直接返回不合法的值，用 `INT_MIN` 即 `-inf`
- 如果是不合法的天 `i<0`，不可能 hold，但是不持有股票的话，是可以看作合法的边界转移的

```cpp
class Solution {
public:
    int maxProfit(int k, vector<int>& prices) {
        int n=prices.size();
        vector memo(n, vector<array<int,2>>(k+1, {-1,-1}));
        auto dfs=[&](this auto&&dfs, int i, int j, bool hold) ->int {
            if(j<0){
                // not valid
                return INT_MIN/2;
            }
            if(i<0){
                return hold? INT_MIN /2 :0;
            }

            int&res=memo[i][j][hold];
            if(res!=-1){
                return res;
            }

            // buy one, and sell one, is a traction
            if(hold){
                // j-1 in buy
                res = max(dfs(i-1, j-1,false)-prices[i], dfs(i-1, j,true));
                return res;
            }
            else{
                res = max({dfs(i-1, j, false), dfs(i-1, j, true)+prices[i]});
            }

            return res;
        };

        return dfs(n-1, k, false);
    }
};
```

**格外注意一个细节**：我们只需要在卖出或者买入的时候，**记录交易次数的变化**，即 `j-1`。重复记录是不合乎题意的。

1:1转化为递推：

```cpp
class Solution {
public:
    int maxProfit(int k, vector<int>& prices) {
        int n=prices.size();
        vector dp(n+1, vector<array<int,2>>(k+2, {INT_MIN/2 ,INT_MIN/2}));
        // init: -1 th day, cannot hold
        for(int j=1;j<=k+1;j++){
            dp[0][j][0]=0;
        }

        for(int i=0;i<n;i++){
            for(int j=1;j<=k+1;j++){
                // j: times we sell
                dp[i+1][j][0] =
                    max(dp[i][j][0], dp[i][j-1][1]+prices[i]);
                dp[i+1][j][1] =
                    // only one need to decline the j
                    max(dp[i][j][0]-prices[i], dp[i][j][1]);
            }
        }
        return dp[n][k+1][0];

    }
};
```
这里我们仅在买入的时候记录交易次数。

> ```

> ```cpp
> cnt(x) = cnt(x>>1) + (x & 1)
> ```

### [1411. 给 N x 3 网格图涂色的方案数](https://leetcode.cn/problems/number-of-ways-to-paint-n-3-grid/)

这题我们状态很多，怎么有效的进行快速检查呢？这里可用一个二进制小 trick: 将状态拼接成 key 保存。

```cpp
/*
 * @lc app=leetcode.cn id=1411 lang=cpp
 *
 * [1411] 给 N x 3 网格图涂色的方案数
 */

// @lc code=start
#include <bits/stdc++.h>
#include <unordered_map>
using namespace std;

unordered_map<int, int> memo;
const int MOD=1'000'000'000+7;

#define COLOR_PARSE(row, pos) (((row) >> ((pos) * 2)) & 3)

int dfs(int i, int j, int preRow, int curRow, int n) {
    if (i == 0) return 1;
    if (j == 3) return dfs(i - 1, 0, curRow, 0, n);

    int key = (i << 14) | (j << 12) | (preRow << 6) | curRow;
    if (memo.count(key)) return memo[key];

    long long res = 0;
    for (int color = 0; color < 3; color++) {
        // 关键：判断是否与【上一行同列】冲突 (i < n 表示上面有行)
        bool conflict_up = (i < n) && (COLOR_PARSE(preRow, j) == color);
        // 关键：判断是否与【左侧同排】冲突
        bool conflict_left = (j > 0) && (COLOR_PARSE(curRow, j - 1) == color);

        if (conflict_up || conflict_left) continue;

        res = (res + dfs(i, j + 1, preRow, curRow | (color << (j * 2)), n)) % MOD;
    }
    return memo[key] = (int)res;
}



class Solution {
public:
    int numOfWays(int n) {
        return dfs(n, 0, 0, 0, n);
    }
};
// @lc code=end


```

### [P1896.互不侵犯](https://www.luogu.com.cn/problem/P1896)

**状态压缩**即编码状态，并用位运算来模拟问题所需要的运算关系。

#### Problem
在 $N \times N$ 的棋盘里面放 $K$ 个国王，使他们互不攻击，共有多少种摆放方案。国王能攻击到它上下左右，以及左上左下右上右下八个方向上附近的各一个格子，共 $8$ 个格子。

- **input**
只有一行，包含两个数 $N,K$。

- **output**
所得的方案数。

- sample1
- input&1
```
3 2

```
- output&1
```
16

```

- *range*
对于全部数据，$1 \le N \le 9$，$0 \le K \le N\times N$。

#### Solution
为什么这个题要用状态压缩？
我们对于这种矩阵状态转移，往往是一行行处理。但是这会导致一个情况：一行的数据太多。

用一个高维的数组的话，容易知道它的局部性会很差，编码也很麻烦。
- 那么，如果把某一行的国王情况用二进制表示的话，我们就可以只用一个维度，且大小为 $2^{N}$ 来解决了。
- 假设 $N=5$, 则用以表示状态的二进制串有 5bit:
	- $01011_{B}$ 表示, 该行第 0 列，第 1 列，第 3 列有国王，其他列没有。

有个这个编码思想，我们再用位运算表示题述的*约束*就可以了

设第 $i$ 行的状态为 $t$, 第 $i+1$ 行为 $u$
- 不出现攻击左右：`ok(i) = ((t << 1) & t == 0) && ((t >> 1) & t == 0)`
- 每一行的攻击范围：`atck(i) = t | (t>>1) | (t<<1)`
- 不攻击上下：`u & atck(i) == 0`

对于 $i+1$ 行，其能合法的摆放意味着其自己行内不出现左右攻击，且不被上一行攻击，即
```
ok(i+1) AND (atck(i) & u) ==0
```

**约束关系**表示好了，状态转移是怎么样的呢？运算顺序呢？

我们直观思考的话，国王的摆放数量取决于行、列的约束，和已经摆放的国王数量。所以这就是我们使用的三个维度。
$dp(i,j,k)$:
- $i$：第 $i$ 行
- $j$：编码为 $j$ 的状态
- $k$：放置了 $k$ 个国王
---
运算顺序是怎么样的呢？先来理一下依赖关系。

显然，每一行的状态可导出该行的国王数量，所以我们认为状态是一个自变量，国王的数量依赖于状态。所以应该先枚举状态。
- ~~其实，你先枚举国王也是可以的~~这样可以避免复杂的转移计算。

国王的数量，随着我们一行一行的放，显然是单调递增的。枚举顺序是从小到大。

依赖关系就很明确了：我们计算一行的 $dp(i,j,k)$ 的时候，其可以从 $i-1$ 行的所有状态，满足 $dp(i,p,k-amt(j))$ 转移来。$amt(j)$ 表示 $j$ 状态表示的一行中的国王数量（即 binary string 中 `1` 的数量）

$$
dp(i,j,k)=\sum dp(i-1,p,k-amt(j))
$$
- $amt(j)$ 可以预处理，以提高效率。

**边界处理**。

第-1 行（在 dp 中用第 0 维），不放国王的方案数是 1。

这样就解决了这个问题。

```cpp
#include <stdio.h>
using namespace std;
typedef long long ll;

const int MAX_STATE = (1<<9) + 100;
const int MAX_N = 10;
const int MAX_K = 100;

ll ok[MAX_STATE], atck[MAX_STATE], cnt[MAX_STATE];

ll dp[MAX_N][MAX_STATE][MAX_K];

int main()
{
    int n;
    int k;
    scanf("%d %d", &n, &k);

    int tt = 1<<n;
    // init ok, atck, cnt;
    for(int i=0;i<tt;i++){
        cnt[i] = cnt[i>>1] + (i & 1);
        ok[i] =((i<<1) & i) == 0 && ((i>>1) & i) == 0;
        atck[i] = i | (i<<1) | (i>>1);
    }

    ll ans = 0;

    dp[0][0][0] = 1;

    // do it
    for(int i=0;i<n;i++){
        for(int j=0;j<tt;j++){
            for(int l=0;l<=k;l++){
                for(int u=0;u<tt;u++){
                    if(ok[u] && (atck[u] & j) == 0){
                        // ok, add it
                        dp[i+1][u][l+cnt[u]] += dp[i][j][l];
                    }
                }
            }
        }
    }

    for(int i=0;i<tt;i++){
        ans+=dp[n][i][k];
    }

    printf("%lld\n", ans);

    return 0;
}
```

### 最长公共子序列的衍生版: [712. 两个字符串的最小ASCII删除和](https://leetcode.cn/problems/minimum-ascii-delete-sum-for-two-strings/)

#### 思路
本题要求两个字符串的最小 ASCII 删除和，删除某些字符之后，让这两个字符串相等，且删掉的字符 ASCII 加和最小。

两个字符串的总字符 ASCII 加和是一个定值，问题等价为求 ASCII 和最大的公共子序列

即转化为求和最大的公共子序列问题。典型的动态规划。

本题 `s1.length, s2.length` 都控制在 1000 以内，小写字符 ASCII 控制在 200 以内，不会爆 int。

做动态规划就好了。

用 $dp[i,j]$ 表示 $s_{1}[i, \dots]$ 和 $s_{2}[j, \dots]$ 的最大公共子序列和，则转移方程：
$$
dp[i,j]=\begin{cases}
dp[i+1,j+1]+s_{1}[i],s_{1}[i]=s_{2}[j] \\
\min\left\{ dp[i+1,j],dp[i,j+1] \right\} 
\end{cases}
$$
#### Code
```cpp
/*
 * @lc app=leetcode.cn id=712 lang=cpp
 *
 * [712] 两个字符串的最小ASCII删除和
 */

// @lc code=start
#include<bits/stdc++.h>
using namespace std;
class Solution {
public:
    int minimumDeleteSum(string s1, string s2) {
        int n = s1.size();
        int m = s2.size();
        
        // dp[i][j] 表示 s1[i...] 和 s2[j...] 的最大公共 ASCII 子序列和
        // 多开一行一列处理空字符串的情况（初始化为0）
        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));

        // 从后往前倒序遍历
        for (int i = n - 1; i >= 0; i--) {
            for (int j = m - 1; j >= 0; j--) {
                if (s1[i] == s2[j]) {
                    // 字符匹配，保留该字符
                    dp[i][j] = s1[i] + dp[i + 1][j + 1];
                } else {
                    // 字符不匹配，取删除其中一个后的最大值
                    dp[i][j] = max(dp[i + 1][j], dp[i][j + 1]);
                }
            }
        }

        // 计算所有字符的总 ASCII 和
        int totalSum = 0;
        for (char c : s1) totalSum += c;
        for (char c : s2) totalSum += c;

        // 最终结果 = 总和 - 2 * 最大公共 ASCII 和
        return totalSum - 2 * dp[0][0];
    }
};
// @lc code=end
```

别忘了边界情况。这里用 $(n+1,m+1)$ 的 $dp$ 数组更方便。边界可以由空字符串转移过来。

### [洛谷P4310 绝世好题](https://www.luogu.com.cn/problem/P4310)
这题很有趣, 乍一看是个普通 dp，但是 `O(n^2)` 会超时。
联想到 `&` 的性质，我们知道一个满足条件的子序列 $[i,j]$, 若对 $\forall k\in[i+1,j],a[k]\&a[k-1]\neq{0}$，则我们知道，他们两两之间一定有一个二进制 `bit` 是 1. 像桥梁一样把它们串联在一起。

**这实际是一个状态压缩**。

则我们可维护以每一个二进制位结尾，其最长子序列的长度。
转移关系：每一个新的数 `x` 到来，都根据这个数各个位是否为 1，更新所有可能的二进制位的最长子序列长度。

- 如果 `x` 的第 `j` bit 为 1，则 `x` 可以从之前的 `j` bit 的最长子序列转移来，并+1.
- 在更新完 `x` 的所有 bit 的新值之后，我们发现，可以通过 `x` 的这些新 bit 来作为桥梁，串联之前的数。即我们要更新 `j` bit 结尾的最长子序列（反向更新）。
	- 更新成 `x` 的所有 bit 中，能伸的最长的值，作为之前结尾 bit 的新值。


```cpp
#include <algorithm>
#include<bits/stdc++.h>
#include <sys/signal.h>
using namespace std;
int Solution(int&n, vector<int>&a)
{
    // sliding window;
    // special case:
    if(n==1){
        return 0;
    }
    // 用dp表示第k位为1的最大结果。
    // 用位运算是一种聪明的方法。因为其将O(n)转化为了O(n*log m),其中m是数的最大值
    vector<int> dp(32,0);

    for(int i=0;i<n;i++){
        int now=1;
        for(int j=0;j<31;j++){
            if((a[i] & (1<<j) )!= 0){
                // 统计当前数可以从哪些二进制位数转移过来，更新不同转移中的最大值now
                now = max(now, dp[j]+1);
            }
        }

        for(int j=0;j<31;j++){
            if(a[i]&(1<<j)){
                dp[j] = now;
            }
        }
    }

    return *max_element(dp.begin(),dp.end());
}
int main()
{
    int n=0;
    cin>>n;
    vector<int> a(n);
    for(int i=0;i<n;i++){
        cin>>a[i];
    }
    int ans=Solution(n,a);
    cout<<ans<<endl;
    return 0;
}
```
