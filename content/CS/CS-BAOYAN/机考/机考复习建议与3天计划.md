# 机考复习建议与 3 天冲刺计划（2026 开放日）

> 整理自：20/21 级机试经验贴、[[2024.6.1开放日上机题目回忆版]]、[[机考Home]]、[[输入输出]]、[[STL]]、[[好题记录-HaoTi]]

## 一、考试画像

- **形式**：2 小时，3 题 × 100 分，全英文题面，OI 模式（自己写完整程序 + 输入输出，不是只写函数）
- **环境**：Sharif Judge，C/C++ 开 `O2`，C++11，可用 `bits/stdc++.h`
- **机房**：Windows 10，IDE 推荐 **Clion > VSCode（配 gcc）> VS**，DevC++ 备用；预推免有反馈说没配 VSCode
- **计分**：IOI 赛制，按通过比例给分（2024）；本地 VSCode 编译不带 `O2`，OJ 开 `O2`
- **分数参考**：2024 年 ≥200 → 学硕；120~200 → 专硕；<120 → WL。2023 年学硕优营机试 160~280，专硕 100~220
- **底线**：签到题 40 分钟内拿到 80~90 分

## 二、题型演变（不要过拟合）

| 年份 | 场次 | 三题 |
|---|---|---|
| 2023 | 开放日 | 建树（先序+后序 → 每层最右节点）/ 01 背包变体 `sum(v)/sum(c)==K` / 状压 DP |
| 2023 | 预推免 | 机器人模拟 / 模板 HashMap / 简单语言解释器 |
| 2024 | 开放日 | 词频统计（签到）/ 图形三分类（按正确率给分）/ SafePtr 模板类 |

结论：**DP 仍是最常见的传统考点，但模板/工程题连续出现**（2023 预推免 2 题、2024 T3），大模拟也不能完全不看。别像 21 级部分同学那样 all in DP。

## 三、必须掌握的 5 件事

1. **IO 处理**（2023 年大量人死在签到题的地方）
   - `getline + stringstream` 处理「每行个数不定 / 多个空格」
   - `while (cin >> x)` 处理 EOF 读入
   - 空输入特判（如空树）
   - 考场快速测试：Powershell `Get-Content test.txt | a.exe`
2. **STL 常用 API**：`unordered_map` / `map` / `set` / `vector` / `priority_queue` / `lower_bound` / `count` / `sort + lambda`；没事翻 [[STL]] 和 [cppreference](https://zh.cppreference.com)
3. **C++ 模板 / OOP**（2024 真题题型，今年很可能复现）
   - 类模板、`shared_ptr`、`throw std::runtime_error`、运算符重载
   - 直接重写 SafePtr（手写版本 + `shared_ptr` 版本），再写一个 HashMap 类模板
4. **DP 板子**：01 背包定值容量 + 负数下标偏移、LIS 变体、区间 DP、树形 DP、状压 DP + bitset 加速；对照 [[常见DP的简要思路]]
5. **工程防坑**：本地用 `-Wall -Werror -fsanitize=address,undefined` 编译（参考 [[最小调试经验]] 的 Makefile）；`O2` 下数组越界 / 未初始化变量会 RE

## 四、3 天计划

### Day 1（9/1）：保底分 — IO + 模板工程题

- **上午 2.5h｜IO 专项**
  - 重写 2024 T1 词频统计：`getline + stringstream` 读入，`unordered_map` 计数，`sort + lambda` 先按次数降序再字典序
  - 练习不定行数 / 多空格 / EOF 三种输入模板，空输入特判
  - 复习 [[输入输出]]、[[STL]]
- **下午 3h｜模板工程专项**
  - 手写 SafePtr：支持负数 `offset`、三种异常（bad free / out of bound / use after free）
  - 再用 `shared_ptr<vector<T>>` 写一遍优雅版（仓库里有答案，先自己写再看）
  - 写一个 HashMap 类模板（2023 预推免 T2 方向）；顺带练运算符重载 / 矩阵类
- **晚上 1.5h｜环境 + 防坑**
  - 用 [[最小调试经验]] 的 Makefile 编译带 sanitizer 的代码，跑一遍测试
  - 复习 O2 UB 案例；确认考场的 IDE 方案（首选 Clion）

### Day 2（9/2）：高分 — DP 板子 + 大模拟

- **上午 3h｜DP 板子**
  - 01 背包定值容量：`sum(v-c*K)==0` 变形 + 负数容量加偏移（2023 硕士 T3 原题思路）
  - 布尔 DP → 空间压缩 → `bitset` 加速的升级路径（暴力 80 分 → AC）
  - LIS 变体：[力扣 354](https://leetcode.cn/problems/russian-doll-envelopes/)（同大小可叠放）
  - 区间 DP（石子合并 / 涂色）、树形 DP（没有上司的舞会 / 二叉苹果树），对照 [[常见DP的简要思路]]
- **下午 2.5h｜状压 DP**
  - [[好题记录分章/01-动态规划-DP]] 中的 [P1896 互不侵犯](https://www.luogu.com.cn/problem/P1896)（已做过，复习思路）
  - [力扣 LCP 69](https://leetcode.cn/problems/rMeRt2/)（目标串 `welcometonju`）
  - [洛谷 2774](https://www.luogu.com.cn/problem/P2774)：知道状压可拿 80 分即可，正解网络流不用深究
- **晚上 2h｜大模拟**
  - 做一道历次 CSP 第三题（2024 经验贴强烈推荐）或 2023 预推免机器人模拟
  - 练「拆步骤 → 选数据结构 → 边界特判」的流程

### Day 3（9/3）：实战 — 全真模拟 + 收尾

- **上午 2.5h｜全真模拟**
  - 计时 2 小时做 2024 真题三连（词频统计 + 图形分类 + SafePtr），完全按考场流程：英文题面、自写 IO、本地先过样例再跑 O2
- **下午 1.5h｜错题复盘**
  - 失分点回到对应笔记；重看 [[好题记录-HaoTi]] 薄弱章节
  - 默写三个模板：main 模板（`ios::sync_with_stdio(false)` + `solve()`）、getline 输入模板、01 背包定值容量模板
- **晚上 1h｜考前清单**
  - 过一遍真题回忆，默写考场策略
  - 准备英文题面常见词（out of bound / use after free / store / load / offset 等）
  - 早点休息，别通宵

## 五、考场策略

1. 前 40 分钟优先保证签到题 80~90 分
2. 遇到不会的题果断跳过，IOI 比例给分，暴力 / 部分分解法优先
3. 2024 T2 的教训：正确率类题目达不到阈值就是 0 分（直接输出 `rectangle` 只有 0.32 正确率 → 0 分），别在难题上硬刚；真遇到图形题，可以用「上下左右四个极点选三做叉乘，与面积比比值」的技巧
4. 本地样例过、OJ 全 RE → 查 O2 下的 UB（未初始化、越界）
5. 现场 OJ 卡顿、pending 是常态（2023 延了半小时），心态放平
