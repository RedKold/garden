我是南京大学计算机金融实验班 2023 级本科生，现在大三。这个跨学科班级让我同时接受计算机与金融的训练：计算机侧修读了操作系统、计算机系统基础、编译原理、计算机网络、数字逻辑与计算机组成等课程，金融侧修读了公司金融、金融工程、货币银行学、金融风险管理，数学侧以概率论与集合论打底。在校期间，我具备较扎实的编程与动手能力：CSP 认证位列前 10%，美国大学生数学建模竞赛获 Honorable Mention，英语六级 587 分，并担任 2025 级计金朋辈导师。真正让我确立方向的，是两项科研与实践。在大学生创新训练项目中，我跟随黄老师研究系统性金融风险度量，用蒙特卡洛重要性采样与 MCMC（Metropolis-Hastings）方法，在尾部条件（市场收益低于 VaR）下估计 MES（边际期望损失），并与朴素估计对比，更稳健地刻画极端行情下的风险贡献，由此走通了"定义指标—设计方法—代码实现—数值验证"的科研闭环。在券商实习中，我围绕"大模型+证券业务"搭建可落地方案：用 Docker 与 Ollama 部署并评测 DeepSeek 与 Qwen 等开源大模型，基于 Dify 与 RAGflow 构建检索增强知识库，优化文本分段、嵌入模型与混合检索+rerank 召回策略，并用 Prompt 工程降低幻觉；再结合 Function Calling 搭建智能体，实现任务规划与工具调用，落地了客户资产负债查询、保证金维持担保比例计算等接口。此外，我在计算机系统基础作业中实现过 ELF 文件解析，在计算机网络课程中用 C 语言 socket 实现过 HTTP 服务器，对底层系统有持续兴趣。综上，我的研究旨趣集中在一个交叉点：用计算机与数据的方法理解并解决金融中的风险与效率问题，具体包括系统性金融风险的度量化建模（基于尾部风险、极端事件与依赖结构的稳健估计）、量化方法与机器学习在资产定价与组合管理中的应用，以及大模型在投研、风控、合规等场景的可靠落地，尤其是降低幻觉、提升可解释性与安全性。我倾向于做面向真实问题、可落地、可验证的研究，希望接受更系统的训练，在金融工程与金融科技方向打牢理论与方法论基础。从河北秦皇岛到南京大学的三年，让我逐渐明白自己想做什么；我希望以研究生阶段为新起点，延续"寻找与理解"，去理解金融世界的风险与不确定性，也用计算机的严谨处理它们。
