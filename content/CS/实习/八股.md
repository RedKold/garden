## 操作系统
#### 进程和程序的区别？
程序 (Program) ：是存放在硬盘上的一个**静态文件**
进程（Process）: 是程序在计算机上的一次动态执行过程，它是操作系统分配资源（内存、CPU time）的最小单位

#### 进程和线程的区别
Process 是程序在操作系统中的一个实例。每个进程都有自己的地址空间、系统资源和程序计数器。进程之间不共享这些资源

Thread 是 Process 内的子执行单元，共享相同的地址空间和系统资源。多个线程在同一个进程内运行，可以互相访问相同的内存区域。线程的主要特点包括
- 共享资源
- 通信
- 切换开销

#### 哪些资源是线程共享的？哪些资源是线程独占的？
- 线程共享 (Shared)
	- Code Section
	- Data Section
	- Heap
	- File Descriptor
	- Sighnal Handlers

- 线程独占 (Private)
	- PC, Program Counter
	- Stack
	- Register Set
	- ID (TID)
	- Errno



#### 线程的通信方式？
- 锁机制 Mutex
- 信号量
- 条件变量

- 事件/线程


#### 物理地址、逻辑地址、虚拟地址

#### **物理地址 (Physical Address)**
- **定义**：内存单元真正的、真实的地址。
- **位置**：地址总线上产生的电信号，直接对应内存条（RAM）上的存储位置。
- **形象比喻**：你的房子在地球上的**经纬度**。无论你给房子取什么名字，经纬度是它在物理世界唯一的、真实的坐标。
    
#### **逻辑地址 (Logical Address)**
- **定义**：由 CPU 生成的地址。在 C/C++ 程序中取地址符 `&` 得到的往往就是逻辑地址。
- **特性**：它是相对于当前进程段的偏移量。
- **形象比喻**：在酒店里，你住的是“**302 号房**”。这个“302”是相对于这层楼的编号，而不是它在地球上的物理位置。

#### **虚拟地址 (Virtual Address)**
- **定义**：在使用了虚拟内存管理技术的系统中，逻辑地址通常指的就是虚拟地址。它为每个进程提供了一个连续、独立的巨大地址空间（例如 4GB 或更高）。
- **意义**：它让进程觉得它拥有了整个内存，而不用担心和其他进程冲突。


## 计算机网络

#### UDP 和 TCP 的区别

UDP 是无连接的，保证最小的可用性

TCP 是有连接的，通过三次握手四次挥手，丢包处理机制等保证可靠的传输。

首部的字段？

#### TCP 如何保证可靠传输

主要依靠这几项：
- 建立连接（三次握手）
	- A (SYN)
	- B (SYN + ACK)
	- A (ACK)
- ACK 和 SEQ（核心）
- 超时重传
- 去重和有序传输
- 数据校验 (Checksum) 和拥塞控制



#### SYN 洪泛攻击
SYN 洪泛攻击（SYN Flood Attack）是一种经典的拒绝服务供给（Dos/DDos）。利用三次握手协议的漏洞，试图让服务器的资源耗尽。

发送 SYN，服务器会分配一定资源给这个半连接的会话，回复 `SYN + ACK`，但是攻击者伪造了 src IP，或者攻击者不回复 ACK，所以服务器会不断地发送 SYN。
