# 行列式
- **计算公式**： $\det(A)=\sum_{j=1}^{n}(-1)^{1+j}a_{1j}M_{1j}$
- **余子式**：余子式是一个矩阵通过**删去**某一行和某一列得到的子矩阵的*行列式*, $M_{ij}$ 就是阐述第 $i$ 行和第 $j$ 列得到的子矩阵的行列式
- **代数余子式**：在余子式上乘以一个符号因子 $C_{ij}=(-1)^{i+j}M_{ij}$

> *determinant* of a *transformation* is a special scaling factor to measure the factor by which a linear transformation changes any area
- if *determinant* is negative, then it change the orientation
