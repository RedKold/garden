## 了解 procfs

**procfs**（全称 Process Filesystem）是 Linux 系统中的一种**虚拟文件系统**。它通常被挂载在 `/proc` 目录下。

由于它不是存储在硬盘上的真实文件，而是在内存中由内核动态生成的，因此它也被称为“伪文件系统”。

---

### 它是干什么用的？

你可以把它想象成**内核向外界打开的一扇窗户**。

- **查看状态**：通过读取 `/proc` 下的文件，用户空间（User Space）的程序（如你正在写的 `pstree`）可以获取内核的运行信息（进程、内存、CPU、网络等）。
    
- **修改配置**：通过向某些特定的文件写入内容，你可以直接在不重启系统的情况下修改内核参数。
    

---

### procfs 的核心特点

- **大小为 0**：如果你在终端输入 `ls -l /proc/stat`，你会发现它的文件大小显示为 **0**。但当你用 `cat` 命令读取它时，却能看到大量数据。这是因为数据是当你发起“读取”请求时，内核临时生成的。
    
- **进程目录**：`/proc` 下每一个以**数字**命名的文件夹，都代表一个正在运行的进程。文件夹的名字就是该进程的 **PID**。
    
- **内存驻留**：它不占用任何磁盘空间，只占用少量的内存。
### procfs 里的重要文件（以你的实验为例）

在实现 `pstree` 时，你会频繁接触到以下内容：

| **文件/目录**          | **作用**                                    |
| ------------------ | ----------------------------------------- |
| `/proc/[pid]/comm` | 存储该进程的可执行文件名（通常就是你想要的进程名）。                |
| `/proc/[pid]/stat` | 包含进程的状态信息，包括 PID、进程名、状态位、**PPID（父进程号）**等。 |
| `/proc/meminfo`    | 系统的内存使用情况（`free` 命令就是读这个）。                |
| `/proc/cpuinfo`    | CPU 的详细架构和频率信息。                           |

所以我们如果能访问 procfs，构建进程树就不是问题了
