# 三地址代码

- 每条指令右侧最多有一个运算符
	- 一般情况可以写成 $x=y\;op\;z$
- 允许的 **运算分量** （地址）
	- 名字：源程序中的变量名字作为三地址代码的地址
	- 常量：源程序中出现或生成的常量
	- 编译器生成的临时变量


## 指令集合
- 运算/赋值
	- $x=y\;op\;z$, $x=\;op\;y$
- 复制指令
	- $x=y$
- 无条件转移指令
	- $goto\;L$
- 条件转移指令
	- $\mathrm{if}\;x\;goto\;L$
	- $\mathrm{if}\;False\;x\;goto\;L$
	- $\mathrm{if}\;x\;relop\;y\;\mathrm{goto\;}L$

- 过程调用/返回
	- param $x_{1}$
	- param $x_{2}$
	- ...
	- param $x_{n}$
		- call $p,n$ // 调用过程 $p$ , $n$  为参数个数（可能嵌套调用）
- 带下标的复制指令：$x=y[i]$, $x[i]=y$
	- $i$ 表示距离数组位置 $i$ 个内存单元（字节），不是数组的第 $i$ 个元素
- 地址/指针赋值指令
	- $x=\&y$ 
	- $x=^{*}y$
	- $^{*}x=y$

## 表示

### 四元式表示 (quadruple)
- 四元式（quadruple）：可以实现为记录（或结构）
```
格式		op	arg1	arg2	result
		+	y		z		x
```
- $op$: 运算符的内部编码
- $arg_{1},arg_{2},result$ 是地址
- $x=y+z$: 见上面表示

- 单目运算符不使用 $arg_{2}$
- param 运算不使用 $arg_{2}$ 和 $result$
- 条件/非条件转移将目标标号放在 $result$ 字段

### 三元式表示（triple）
```
格式		op	arg1	arg2
```
- 使用三元式的***位置***来引用运算结果

- $x=y\;op\;z$
```
- 	?	op	y		z
-		=	x		(?)
```

我们通过 $(?)$ 引用了上一条指令的运算值

- 我们需要规定一下 $x[i]=y$ 的指令顺序（保证一致性来完成作业）

![image.png|400](https://kold.oss-cn-shanghai.aliyuncs.com/20260415114222.png)


```
			op		arg1	arg2	result
x=y[i]:		=[]		y		i		x
x[i]=y:		[]=		i		y		x

			__		op		arg1	arg2
x=y[i]:		0		=[]		y		i
			1		=		x		(0)			
x[i]=y:
			0		+		x		i

```

# 类型和声明
- 类型检查 (type checking)
	- 利用一组规则来检查*运算分量*的类型和运算符的预期类型是否匹配
- 类型信息的用途
	- 查错、确定名字需要的内存空间、计算数组元素的地址、类型转换、选择正确的运算符
- 本节的内容
	- *确定名字的类型*
	- *变量的存储空间布局* （相对地址）

## 类型表达式 (type expression)
- 表示类型的结构
	- 基本类型？
	- 类型构造算子？
- `int [2][3]`：表示由两层数组组成的数组

## 类型等价
- 结构等价 (structurally equivalent)
	- 相同的基本类型，or
	- 由相同的构造算子作用于等价的类型而得到，or
	- 一个类型是另一个类型表达式的名字
- 名等价 (name equivalence)
	- 类型名仅代表自身（仅有前两个条件）

## 类型的声明
- 处理基本类型、数组类型或记录类型的文法
	- $D\to T\;id;\;D\;|\;\varepsilon$
	- $T\to B\;C\;|\;\mathrm{record}$
	- $B\to \mathrm{int}\;|\;\mathrm{float}$
	- $C\to\varepsilon\;|\;[num]\;C$
## 局部变量的存储布局
- 确定变量需要的内存
	- **类型的宽度**
	- 可变大小的数据结构只需要考虑指针
	- special: aligned, padding, pack
- 函数的局部变量 **总是** 分配在 **连续** 的区间
	- 因此给每个变量分配一个相对于这个区间开始处的相对地址
- 变量的类型信息保存在 **符号表** 中
