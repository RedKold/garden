## 1. 操作系统

### 高频押题

- **条件变量万能模板（必考）**：会写、会解释
```cpp
  mutex_lock(&lk);
  while (!check_condition()) {
      cond_wait(&cv, &lk);   // 原子地“释放锁 + 睡眠”
  }
  /* 临界区 */
  mutex_unlock(&lk);
```



  唤醒用 `signal`（一个）或 `broadcast`（全部）；生产者-消费者中防止 producer 唤醒 producer 时用 broadcast。
- **进程管理**：fork 复制状态机（父返回子 PID、子返回 0）；execve 是唯一执行程序的系统调用；_exit/exit_group 销毁进程。
- **fork 与缓冲区陷阱**：fork 复制全部状态含 libc 缓冲；管道输出时 `printf` 缓冲被继承，输出行数翻倍；`fflush` 可解决。
- **死锁**：四个必要条件（互斥、持有并等待、不可抢占、循环等待）；Lock ordering 为什么有效（持最大号锁者总能继续）。
- **信号量**：P/V 语义；互斥锁 = 初值 1 的信号量；哲学家问题两种解法（限制 4 人上桌 / 锁排序）。
- **崩溃一致性**：追加文件要写 3 处（bitmap、数据块、inode），8 种成败组合——(011) 数据+inode 已写而位图未写最危险（块被复用）；(101) 位图+inode 而无数据 = “gap”（读到旧内容）。
- **WAL / journaling**：TxBegin → 操作 → flush → TxEnd → flush → checkpoint → 回收；ext3 三种模式：journal（全量）、ordered（先 data 后 metadata，默认）、writeback（仅 metadata）。
- **磁盘 I/O 时间**：T = 寻道 + 旋转延迟 + 传输时间；SSTF 可能饥饿。

### 易错点

- 程序是静态状态机，进程是运行中的状态机。
- 自旋锁是用户态原子操作，空转浪费 CPU；内核锁用“关中断 + 自旋”（futex）。
- 并发 bug 两类：原子性违反（ABA）与顺序违反（BA）。
- 安全保存文件：write tmp → fsync(tmp) → rename（原子）→ fsync 目录，顺序不能乱。

## 2. 计算机组成（DLCO）

### 高频押题（笔记 Review 明确点名）

- **卡诺图化简（必考）**：找质蕴含项 → 必须包含所有实质蕴含项 → 最小覆盖；相邻含跨边；可用无关项化简。
- **D 触发器定时（必考）**：`t_clk2q`（边沿到输出变化）、`t_setup`（边沿前数据须稳定）、`t_hold`（边沿后须保持）。
  - 时序约束：`t_clk > t_ffpd(max) + t_comb(max) + t_setup`
- **时序电路设计（必考）**：功能分析 → 状态图/状态表 → 状态化简（等价状态合并）→ 状态编码（相邻法）→ 逻辑表达式 → 画图；注意未用状态分析（挂起 / 自启动）。
- **CPU 两道大题：多周期 + 流水线**
  - 多周期：每阶段一个时钟（IF / ID / EX / M / WB），不同指令周期数不同，功能部件复用，需要 IR、MAR、MDR、PC 写使能；控制器用状态转移图（PLA 或微程序）。
  - 流水线：三种冒险（结构/数据/控制）；数据冒险解法（阻塞、NOP、寄存器先写后读、转发、编译重排；load-use 需等一条）；控制冒险（静态预测冲刷 C 条、动态 BHT 两位预测、延迟分支）。
- **性能比较**：单周期 = 最慢指令总延迟（例题 load 600ps）；多周期 = Σ(指令比例×周期数)×最长阶段（例题 824ps）；流水线周期 = 最长阶段，CPI ≈ 1 + 冒险惩罚。
- **乘法**：无符号（判断-加-右移）；原码（符号分开，用于浮点尾数）；补码 Booth（01→+X、10→−X、00/11→+0，算术右移）；溢出判断（无符号看高 n 位全 0）。

### 易错点

- 标志位：`OF = C_n ⊕ C_{n-1}`；`SF = F_{n-1}`；`ZF ⟺ F=0`；`CF = Cout ⊕ Cin`。
- 锁存器（电平触发）vs 触发器（边沿触发）；T 触发器 `Q* = T⊕Q`。
- 行波计数器 `1111→0000` 需 4 级触发器延迟；同步计数器只需 1 个与门 + 1 级锁存延迟。
- 组合逻辑无记忆、无反馈；关键路径 = 最长路径延迟之和。

## 3. 数据结构（算法设计与分析）

### 高频押题

- **Prim / Kruskal**：都能看作 MCE（最小跨切边）框架；MST 性质 = **非树边加入后是环中最大边。**
  - Prim：fringe + 优先队列，$O((n+m)\log n)$；数组 $O(n^{2}+m)$。
  - Kruskal：边排序 + 并查集判环，$O(m \log m)$。
- **Dijkstra**：边权非负才成立；堆实现 O((n+m)log n)（n 次 extract-min + m 次 decrease-key，各 O(log n)）；第一次弹出即定稿；最短路径树 ≠ MST。
- **Floyd**：k 必须最外层（阶段），O(n³)，可检测负环。
- **拓扑序**：DAG 上 DFS 按 finish time 逆序编号，O(n+m)。
- **并查集**：加权并 + 路径压缩，操作近常数（log*）；可手写 find/unite 模拟。
- **DP 大题**：矩阵链乘 O(n³)、编辑距离 O(mn)、LIS（状态必须“以 i 结尾”，否则依赖信息丢失）。
- **哈希**：闭地址 Θ(1+α)；开地址 α<1，不成功查找 ≤ 1/(1-α)。
- **主定理**：T(n)=bT(n/c)+f(n)，E=log_b c；三种情况对号入座。
- **伪多项式**：背包 O(nW) 是伪多项式（W 按输入位数是指数）。

### 易错点

- 无向图 DFS 只有树边+回边；BFS 只有树边+交叉边；白路径定理对 BFS 不成立。
- 割点：`w.back ≥ discover(v)`；桥：`v.back > discover(u)`。
- 欧拉图（走遍边）= 连通且度数全偶；Hamilton（走遍点）只有必要/充分条件，无充要判定。
- 二部图 <=> *无奇圈* <=> 2-着色；Hall 定理 `|N(A)| ≥ |A|`。

## 4. 计算机网络

### 高频押题（笔记标了“必考”）

- **TCP 头部（20B）**：序列号是字节偏移；累计 ACK；3 个重复 ACK → 快速重传。
- **IP 头部动态部分**：TTL 每跳减 1；校验和只对首部计算且 TTL 变后重算；Total Length 不含以太网头。
- **分片计算**：Identification 相同；DF=1 禁分；MF=1 还有后续；Fragment Offset 以 8 字节为单位（非尾片数据长度必须是 8 的倍数）；重组只在目的主机。
- **拥塞控制**：慢启动（每 RTT 翻倍）→ 拥塞避免（每 RTT +1 MSS）；超时 cwnd=1；3 dupACK cwnd 减半 + 快恢复；Tahoe / Reno / NewReno 区别；实际窗口 = min(cwnd, rwnd)。
- **Max-Min 公平性（必考）**：每轮剩余资源均分给未满足者，达到需求的退出；优先满足小需求用户。
- **DHCP 四步（必考）**：Discover → Offer → Request → ACK（Discover 用广播 0.0.0.0→255.255.255.255）。
- **NAT（必考）**：静态 / 动态 / 单地址（PAT，用端口区分）；隐藏内网、兼防火墙；私有网段 10 / 172.16 / 192.168。
- **CIDR（必考）**：A.B.C.D/n；子网划分计算题。
- **隐藏终端（必考）**：RTS → CTS → DATA → ACK 四帧交换。
- **CSMA/CD**：最小帧长 64B（保证冲突可检测）；二进制指数退避（K×512 比特时间）。
- **时隙 ALOHA**：最大效率 1/e ≈ 0.37。
- **CRC**：R = D·2^r 除以 G 的模 2 余数（r = G 位数 − 1），模 2 除法即异或。
- **距离向量**：count-to-infinity；毒性逆转只对“下一跳是自己”的邻居有效，≥3 节点仍可能失效。
- **BGP**：路径向量，AS Path 含自己 AS 号即丢弃（防环）；基于策略选路；eBGP / iBGP。

### 应用层速记

- FTP：TCP，控制 21 + 数据 20（每文件一条数据连接）。
- SMTP：25 端口，只传 ASCII；POP3 下载邮件；IMAP 服务器上管理。
- DNS：根 / TLD / 权威 / 本地；递归 vs 迭代。
- HTTP 无状态；持久连接 + 流水线：小文件首次 2 RTT、之后 1 RTT。
- RSA：公钥 (e,N)、私钥 (d,N)；C = M^e mod N；安全性靠大数分解。
- QoS：漏桶（恒定速率）vs 令牌桶（速率 r、容量 b，t 内最多 rt+b，允许突发）。

## 5. 离散数学

### 高频押题

- **CRT 计算**：x ≡ Σ aᵢ·Mᵢ·tᵢ (mod M)，Mᵢ = M/mᵢ，Mᵢ·tᵢ ≡ 1 (mod mᵢ)。例题：x≡2(mod3), x≡3(mod5), x≡2(mod7) → x≡23(mod105)。
- **欧拉函数**：φ(n) = n·∏(1−1/p)；欧拉定理 a^φ(n)≡1；费马小定理 a^(p−1)≡1 (mod p)。
- **关系性质判定**：自反（主对角全 1）、反自反（全 0）、对称（矩阵对称）、反对称、传递（R²⊆R）；空关系既对称又反对称又传递。
- **传递闭包 Warshall（手算）**：W_k[i,j] = W_{k-1}[i,j] ∨ (W_{k-1}[i,k] ∧ W_{k-1}[k,j])，O(n³)。
- **群论**：验证群四步（非空、结合、幺元、逆元）；子群判定优先 `ab⁻¹ ∈ H`；拉格朗日 |G| = |H|·[G:H]；循环群生成元 φ(n) 个（a^k 是生成元 ⟺ gcd(k,n)=1）。
- **格与布尔代数**：格 = 任两元素都有 lub/glb 的偏序集；布尔代数 = 有补分配格；有限布尔代数基数必为 2^n。
- **图论**：握手定理 Σd = 2m（奇度顶点偶数个）；欧拉图判定（全偶度）；Hamilton 必要 p(G−S) ≤ |S|、充分 Dirac/Ore；二部图（无奇圈）；Berge（最大匹配 ⟺ 无增广路径）、Hall 定理。
- **计数**：容斥原理（奇加偶减）、鸽笼原理、Vandermonde 恒等式。

### 易错点（笔记原文）

1. 群验证四步一个都不能省；
	1. 代数系统（封闭性）
	2. 结合性（半群）
	3. 都有单位元（幺半群）
	4. 都有逆元（群）
2. 判定子群优先用 ab⁻¹∈H；
3. 循环群生成元个数是 $\varphi(n)$，不是 $n$；
4. 格 ≠ 偏序集，还要任意两元素有上下确界；
5. 布尔代数一定是有补分配格，有限布尔代数基数必为 2^n；
6. 群的阶 ≠ 元素的阶（Klein 四元群：4 阶群但没有 4 阶元）。

## 6. 编译原理

### 高频押题（来自 Compilers-Review 重要考点）

- **LR 项集自动机的构造（必考）**：增广文法 S′→S → 初始项集 CLOSURE({S′→·S}) → 反复 GOTO(I, X) 求闭包 → 得项集族 → 填 ACTION/GOTO 表。
- **SLR / LR(1) / LALR 对比**：
  - SLR = LR(0) + FOLLOW 过滤归约；
  - LR(1) 项 [A→α·β, a] 带向前看符号；
  - LALR = 合并同核心 LR(1) 项集（向前看取并），状态≈LR(0)、能力≈LR(1)；不引入 s/r 冲突、可能引入 r/r 冲突；
  - 能力：LR(0) ⊂ SLR ⊂ LALR ⊂ LR(1)。
- **自动机**：NFA→DFA 子集构造（ε-closure、move）；DFA 最小化（可区分/不可区分状态）。
- **语义动作人肉模拟（必考）**：后缀 SDT 在归约时执行；属性在栈上（union）；会推 while / if / 布尔表达式的 SDT 与标号放置顺序。
- **静态分析算法人肉模拟（必考）**：到达定值（前向 ∪）、活跃变量（逆向 ∪）、可用表达式（前向 ∩）；会写 OUT = gen ∪ (IN − kill) 并迭代求解。
- **常见结构到 IR 翻译（必考）**：数组寻址（base + i×w）、布尔短路（跳转实现，逻辑运算符不出现）、回填（makelist/merge/backpatch）。
- **运行环境**：活动记录内容（返回值/参数/控制链/返回地址）；四种垃圾回收对比（引用计数、标记-清扫、标记-压缩、拷贝）。
- **优化**：基本块 DAG（局部公共子表达式、死代码、常量折叠）；复制传播是使能优化；代码移动（循环不变式外提）；归纳变量 + 强度衰减（乘法→加法）。
- **代码生成**：寄存器/地址描述符、getReg、溢出 spill。

### 易错点

- 句柄是最右推导“最后一步”展开的产生式体，且总在栈顶。
- 消除左递归只影响自顶向下；自底向上（LR）不需要消除左递归。
- LALR 合并后可能新增归约-归约冲突，但绝不会新增移入-归约冲突。
- 一个分析树对应唯一最左推导和最右推导；二义性 = 一个句子有多棵分析树。
